# Qub-its landing page

Landing corporativa de Qub-its construida con Svelte 5 y Vite.

## Desarrollo

Requiere Node.js 20.19 o superior.

```bash
npm run dev
npm run build
```

Las rutas históricas de privacidad y productos se resuelven por la aplicación. En Vercel, `vercel.json` asegura el fallback para accesos directos.
